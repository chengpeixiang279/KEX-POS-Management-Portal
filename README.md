# KEX POS 管理门户 - 完整版（高保真原型）

KEX（Kerry Express）POS 管理门户的完整版高保真 UI 原型，在基础版之上新增公司 / 门店信息、物料样式、设备操作文档中心等模块。

## 模块

- 运单信息（PBR/MSP Delivery Note）
- 收据管理（Receipt Management）
- 税务发票管理（含 VAT 校验）
- 门店管理（Store Management）
- 公司信息 / 门店信息维护
- 物料样式配置与个人档案
- 系统指导与设备操作文档中心

## 技术栈

- HTML / CSS / JavaScript（原生，单文件，无构建、无后端）

## 如何运行

浏览器打开 `index.html` 即可。

## 说明

高保真 UI 原型，数据为静态示例，未接后端。
